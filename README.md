# 拾贴

一个为 Windows 设计的轻量文字剪贴板。它使用系统原生 WinForms 和事件式剪贴板监听，不轮询、不联网，也不依赖 Electron 或第三方组件。

## 功能

- 自动记录复制过的文字和图片，默认最多保留 10 条
- 图片会以缩略图保存在历史中，支持单独重新复制和删除
- 每条记录都有独立“复制”按钮
- 最近一次单条或批量复制所包含的记录会在按钮上保持“✓ 已复制”高亮，直到下一次复制时整体更新
- 每条记录都可勾选；勾选多条后可批量复制或批量删除，批量复制时每条内容换行排列
- 长按任一记录后向上或向下拖动，可快速连续多选；拖到列表边缘会自动滚动，滚动速度随鼠标移动速度变化
- 多选后可点击“复制所选”，也可按 `Ctrl + C` 复制；需要重新选择时可点击“取消所选”
- “复制全部”按面板当前顺序合并内容，条目间隔一个空行
- “清空”一键清除，并提供短暂的撤销入口
- 标题栏提供置顶和设置图标，鼠标悬停会显示说明；置顶开启后窗口会保持在其他窗口上方并记住设置
- 默认用 `Ctrl + Shift + V` 唤醒或隐藏；在设置中点击快捷键按钮，再直接按下新的组合键即可更换
- 可即时切换 8 种界面颜色：同温层蓝、南极星蓝、星辰绿、银河紫、曙光金、霞光橙、镜空粉、星灰
- 使用与软件一致的自绘顶部栏和窗口边缘，拖动四边或四角即可缩放，最小可缩至 `280 × 340`
- 拖动顶部空白区域可移动窗口，双击顶部可最大化或还原；尺寸和位置会自动记住
- 关闭窗口或最小化时收进系统托盘，托盘菜单可彻底退出
- 历史与设置保存在 `%LOCALAPPDATA%\QuietClip\state.json`

为控制内存占用，单条超过 100 万字符的文字会被跳过。图片不设边长或文件大小限制；重复内容再次复制时会移到列表顶部，不会产生重复项。多选复制适用于文字；图片可单独复制，多选删除同样支持图片。

## 运行

双击 `启动拾贴.cmd`。首次运行会自动构建，然后打开程序。

也可以在 PowerShell 中手动构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建结果位于 `dist\QuietClip.exe`。项目直接使用 Windows 自带的 .NET Framework 4.x 编译器，无需下载依赖。
